# Netsekurity messaging reference

The current content direction is recorded in [PLAN-content-redesign.md](PLAN-content-redesign.md).
Public product claims and their implementation evidence are maintained in [CLAIMS.md](CLAIMS.md).

Primary offer: practical external website security checks that customers can repeat
after updates, after repairs and between comprehensive pentests.

Primary reader: the website or application owner. Their developer may handle proof
setup and repairs. Lead with findings, impact and next actions. Explain the actual
scope and English PDF deliverable before purchase.

English headline: Your website keeps changing. Keep checking its security.

Indonesian headline: Website terus berubah. Periksa keamanannya secara berkala.

Primary action: Start a check / Mulai pemeriksaan.
Secondary action: Example results / Contoh hasil.

Use the current database prices. Each check and repeat check uses one credit for
one hostname. Verification supports DNS TXT, an HTTPS file and a homepage meta tag.

Comprehensive pentesting adds agreed depth and scope. The standard external service
does not include authenticated or injection testing and does not promise detection
of all new CVEs. Never claim that a report proves an application is safe.
